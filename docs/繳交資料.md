## E2. 問題與解法摘要

### 版本 A（193 字，建議用這版）

> 內向者常常沒察覺社交能量已經見底，直到崩潰才驚覺；行事曆只管理時間，不管理心理資源。社交電量計用 AI 把社交能量變成一顆看得見的電池：六題快篩定出基礎電量，再依類型、人數、熟悉度與時長預測每場社交的消耗，標出會過載的日子。系統奠基於外向性人格理論與資源保存理論，並導入跨日累積模型——睡一覺只回充八成，前一天的赤字會拖累隔天。以 Next.js 與 Cloudflare 部署，事後回報持續校準。

